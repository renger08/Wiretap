# Wiretap

بازسازی تحت‌وب رابط کاربری سیستم شنود از سریال *The Wire*؛ طراحی‌شده به‌عنوان یک تجربه‌ی محیطی (Ambient) که می‌تواند به‌صورت مداوم اجرا شود.

**[▶ نسخه آنلاین — وب‌سایت شخصی](https://wiretap.thealinabati.ir/)**
**[▶ نسخه آنلاین — GitHub Pages](https://renger08.github.io/Wiretap/)**

![Wiretap](./assets/wiretap_v2.gif)

## Wiretap چیست؟

*Wiretap* در ابتدا به‌عنوان یک پروژه کوچک برای **Raspberry Pi Zero 2 W** شروع شد: یک مانیتور، چند بلندگو و صفحه‌ای الهام‌گرفته از کامپیوتر شنودی که جیمی مک‌نالتی، لستر فریمن و تیم شنود در سریال *The Wire* از آن استفاده می‌کردند.

ایده ساده بود: دستگاه را روشن کن، رهایش کن و بگذار مثل یک ایستگاه شنود قدیمی در گوشه‌ای از اتاق به کار خودش ادامه دهد.

پروژه بعدها به یک تجربه‌ی تحت‌وب تبدیل شد که می‌تواند مستقیماً روی کامپیوتر، لپ‌تاپ یا یک نمایشگر اجرا شود.

این پروژه عمداً به‌عنوان یک **تجربه‌ی محیطی و خودکار** طراحی شده، نه یک برنامه‌ی تعاملی.

## نحوه کار

پس از شروع، رابط کاربری به‌صورت مداوم چرخه‌ی زیر را اجرا می‌کند:

```text
STANDBY
   ↓
DIALING
   ↓
RINGING
   ↓
CONNECTED — RECORDING
   ↓
CALL ENDED
   ↓
STANDBY
```

در هر چرخه، یک فایل صوتی به‌صورت تصادفی انتخاب می‌شود، شماره تلفن مربوط به آن روی صفحه نمایش داده می‌شود، شماره به‌صورت رقم‌به‌رقم با صداهای DTMF شماره‌گیری می‌شود، سپس فایل صوتی پخش شده و هم‌زمان در نمایشگر Waveform پردازش و نمایش داده می‌شود.

یک تماس مشخص هیچ‌وقت بلافاصله دوباره انتخاب نمی‌شود.

## قابلیت‌ها

* ۲۱ فایل صوتی تماس
* انتخاب تصادفی تماس‌ها
* جلوگیری از تکرار فوری یک تماس
* شماره‌گیری رقم‌به‌رقم
* تولید صدای DTMF
* تولید صدای زنگ تلفن
* نمایش Waveform واکنش‌گرا به صدای واقعی
* نمایش طیف فرکانسی (Frequency Spectrum)
* افکت‌های تصویری به سبک CRT
* نمایش ساعت سیستم
* نمایش مدت زمان تماس
* اجرای خودکار و مداوم چرخه
* مقیاس‌دهی خودکار برای اندازه‌های مختلف نمایشگر
* طراحی مناسب برای نمایش افقی در موبایل
* طراحی اولیه بر اساس رزولوشن 1366×768
* پردازش صدا با Web Audio API

## اجرای محلی

Wiretap یک پروژه‌ی استاتیک است و به Backend یا سیستم Build نیاز ندارد.

از آنجا که مرورگرها هنگام باز کردن مستقیم فایل HTML با `file://` ممکن است دسترسی به صدا و برخی منابع را محدود کنند، بهتر است پروژه را با یک HTTP Server محلی اجرا کنید.

### Python

```bash
python -m http.server 8000
```

سپس در مرورگر باز کنید:

```text
http://localhost:8000
```

می‌توانید از سرورهای محلی دیگری مانند XAMPP نیز استفاده کنید.

## سلب مسئولیت

Wiretap یک **پروژه‌ی غیررسمی و ساخته‌شده توسط طرفداران** است که از مجموعه تلویزیونی *The Wire* الهام گرفته است.

این پروژه هیچ وابستگی، تأیید یا ارتباط رسمی با HBO، David Simon یا سازندگان *The Wire* ندارد.

هدف پروژه، استفاده‌ی طرفداری، آموزشی و آزمایشی است.

فایل‌های صوتی و ارجاعات مربوط به این مجموعه متعلق به صاحبان حقوق مربوطه هستند.

## اعتبار و الهام

این پروژه از رابط‌های کاربری سیستم‌های شنود و فضای کلی سریال *The Wire* الهام گرفته است.

به‌طور ویژه، سیستم شنود و ایستگاه کاری مورد استفاده تیم شنود در طول سریال منبع اصلی الهام این پروژه بوده است.
